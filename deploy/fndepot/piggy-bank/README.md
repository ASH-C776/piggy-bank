# 🐷 存钱罐 · Piggy Bank

> 面向家庭的自托管积分管理系统 —— 让孩子在完成任务、赚取积分、兑换奖励的过程中，学会规划与储蓄。

**怎么玩**：孩子完成日常任务，或家长发布的临时任务 → 获得积分 → 用积分在商店兑换商品或现金；
所有申请由家长审核把关。**数据全部保存在你自己的 NAS 上（SQLite 单文件），不上传任何云端。**

---

## 功能特性

### 👨‍👩‍👧 家长端
- **总览**：所有孩子的积分、今日变化、待审核数量
- **积分**：设置日常加分/扣分项目（可限每日次数），一键为孩子加减分
- **任务**：发布临时任务（分类、积分奖励、截止时间）
- **审核**：审批任务完成、商品/现金兑换申请
- **商店**：管理可兑换商品（名称、所需积分、库存）
- **记录**：全部积分流水明细与操作人
- **成长**：记录身高体重，成长曲线对照中国儿童生长标准看百分位；支持多孩子按年龄对齐对比

### 🧒 孩子端
- **首页**：积分余额、生肖头像、等级进度
- **任务**：领取任务、提交完成，等待家长审核
- **商店**：用积分兑换商品，或申请兑换现金

### ✨ 其他
- 家长用账号 + 密码登录；孩子用账号 + PIN 码登录（无需记密码）
- 内置 12 生肖头像，WebSocket 实时推送（家长端审核数即时刷新）
- 响应式设计，手机 / 平板 / 电脑均可使用
- 可自定义兑换比例（如 10 积分 = 1 元）

## 安装说明

在飞牛应用中心 → 手动安装（或通过 FnDepot 安装）本应用包后：

1. 桌面出现「存钱罐」图标，点击即可打开
2. 默认管理员账号：`admin` / `admin123` —— **请登录后立刻在「设置」里改密码**
3. 在家长端添加孩子账号、设置孩子 PIN 码，即可开始使用

> 默认服务端口为 **3000**，如与现有应用冲突，可在应用设置里调整。
> 数据存放在系统托管的应用数据目录中，**升级、覆盖安装都不会丢数据**。
